# Exercise demonstrations

`exercise-demos/` intentionally contains no media yet. Do not download copyrighted videos without permission. Use only owned, licensed or explicitly permitted content; retain license, attribution and source records per exercise asset.

Target: MP4, approximately 5–15 seconds, looping, no audio required. Show a clear start position, complete movement and controlled return. Avoid distracting edits. Use one or two camera angles according to movement complexity.

Goblet Squat, Dumbbell Romanian Deadlift, Bulgarian Split Squat, Reverse Lunge and Single-Leg Romanian Deadlift should have two useful views (for example side and front). Review footage and cues together before assigning a URI. Every Phase 0 URI is null; no fictional external URL is supplied.

Phase 1 should add an asset/rights manifest, file naming by stable exercise ID and angle, encoding/size checks, accessible written alternatives, playback states and physical-device QA. Production video hosting is a later decision.
